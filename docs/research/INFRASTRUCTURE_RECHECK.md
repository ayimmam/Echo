## Proposed deployment baseline after this check

- Android minSdk 29 / arm64 remains. Retain existing toolchain files pending BUILD-01; this review changes no dependencies. Validate actual target-SDK behavior on modern Android and resource constraints on the reference 2 GB phone.
- In-country P1/P2: one capability-selected Python application, one database (PostgreSQL preferred) and bounded scheduled CLI jobs. Shared hosting is conditional; supported Linux VPS is the fallback. No openGauss baseline or shared-host OS/container requirement. Research infrastructure remains unconfirmed; ADR-016 removes Research Mode and the new recording corpus. Existing approved acoustic corpora/live observer records remain separately governed.
- Competition demo is a distinct synthetic deployment using the same selected application/engine where available; ECS/managed DB selections remain conditional. ModelArts/OBS training is a separate optional capability; it is not required to unblock undergraduate capture tests. Record exact region/service quota before booking capacity.
- DB listener and annotation UI are private. Only HTTPS API/demo routes are public. Keep service secrets out of images, source and logs; test certificate rotation, backups and restart recovery. Pilot backups, observability and model artefacts remain in-country for both cohorts.

## Evidence record to complete at G0/G4-U

Record selected host/location, managed gateway (shared) or OS image/container versions (VPS only), Python/API/driver/database versions, region/VPC and service availability, CA/trust configuration, encrypted-backup location/retention, restore evidence, Android dependency lock/checksums, model/converter/runtime hashes and device OS/RAM/page size. Retention, recovery-time and recovery-point objectives must be assigned numerical values by Lead/Sys before tests can pass. Record unresolved items as blocked, not verified.

Scope limits: no cloud account inspection, provider contract, download/binary inspection, build, training, device operation or data transfer was performed. Previous 4 KB AAR binary finding remains dated prior evidence; verify the newly chosen binary. No new legal interpretation is made here.
