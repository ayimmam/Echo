Metadata for DOI-bearing works comes from Crossref (retrieved 2026-09-25); arXiv works from their abstract pages. Article titles are in sentence case as APA requires. Tags were updated 2026-09-26 after reading the full texts supplied in [`papers/`](papers/).

## Status tags

The tag says how far the source was read for this audit. It doesn't judge the source's quality.

| Tag | Meaning |
|---|---|
| **[Full]** | Full text, official page, package or binary opened. |
| **[Abstract]** | Only the abstract or official record (Crossref, ERIC, Europe PMC, arXiv) read. |
| **[Metadata]** | Reference details confirmed; content not yet read. |
| **[Secondary]** | Known only through a secondary summary; confirm before citing. |
| **[To obtain]** | Primary document not yet accessed. |
