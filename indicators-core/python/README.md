# indicators-core / Python reference (DRAFT until gate G1)

Stdlib-only (Python 3.10+) reference for the tick-timeline indicator contract. It is the oracle the
Kotlin port must match to 1e-6. **Status: starter.** It reproduces the 18 prepared acceptance
vectors and the hand-calculated golden cases; the choices the vectors leave open (quantile estimator,
OVERLAP handling inside turns) are marked `DRAFT` in `indicators.py` and must be frozen at G1.

| Module | Role |
|---|---|
| `timeline.py` | Segment model, label schemas, strict tiling validation |
| `indicators.py` | I1–I8 over a validated timeline; unavailable = `None`, never zero |
| `cohort.py` | STEM / early-grade isolation checks (ADR-014) |
| `adapter.py` | `acceptance-v1` stdin → stdout adapter for `tests/acceptance/runner.py` |

Two label schemas are kept apart (ADR-016): `early-grade-v1` (spec 2, five classes) and
`coarse-v0-draft` (spec 3, `ADULT / CHILD_UNSPECIFIED / OVERLAP / NON_SPEECH`). Under the coarse schema
only I-1, I-5 (and the label-agnostic I-7, I-8) can be computed; I-2/3/4/6 report an `unavailable`
reason. Adult voice is a teacher *proxy* only in confirmed single-adult, no-playback lessons.

```sh
python3 -m unittest discover -s indicators-core/python/tests -v
python3 tests/acceptance/runner.py --adapter '["python3", "indicators-core/python/dimts_indicators/adapter.py"]'
```

Golden cases live in `../golden/`. Their expected values were calculated by hand (see each
`rationale`), not generated by this code.
